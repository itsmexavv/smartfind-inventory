Demo walkthrough

Try SmartFind.

Test the main workflow, then inspect how the interface and API work together.

Five-minute walkthrough

  1. Search for notebook to find a low-stock product.
  2. Add a new product with a unique SKU.
  3. Adjust stock by +10 with a delivery reason, then inspect the movement ledger.
  4. Try to remove more units than are available. Stock and history stay consistent.

Run and test

Start the app with python run.py. Run its automated checks with python -m unittest discover -v.

Data and limits

This is a single-user learning demo with synthetic sample data. Authentication and production deployment are outside its current scope.

Records and closures persist in the local data directory. Restarting the app keeps your changes. Use a fresh --data-dir directory for a new synthetic demo.
